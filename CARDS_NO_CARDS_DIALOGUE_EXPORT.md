# Cards No Cards — экспорт диалога по теме проекта

> Экспорт пользовательских сообщений и видимых ответов ассистента из доступной истории этого диалога. Служебные сообщения и вызовы инструментов не включены. Формулировки сохранены настолько близко к исходным, насколько позволяет доступная история.

---

## 1. База данных и минимизация ресурсов

**Пользователь:**  
Давай не postgres а sqlite или аналог, чтобы жрало меньше

**Ассистент:**  
Да, для твоего приложения я бы выбрал SQLite вместо PostgreSQL. Для персонального приложения с одним пользователем это разумное упрощение: меньше потребление памяти, меньше обслуживания и никаких отдельного процесса базы данных.

Сравнение:
- PostgreSQL требует отдельный сервер БД, SQLite — нет.
- SQLite потребляет меньше памяти и проще в обслуживании.
- Для небольшой персональной нагрузки SQLite подходит.
- При большом числе одновременных записей или нескольких экземплярах приложения можно будет пересмотреть выбор.

Важные условия:
- Файл SQLite хранится на постоянном диске, а не во временном слое Docker-контейнера.
- При деплое нельзя удалять его вместе с контейнером.
- Резервные копии отправляются в приватный S3.
- Копирование должно быть безопасным с учётом SQLite/WAL, а восстановление нужно периодически проверять.

**Ассистент:**  
Обновил оба документа под SQLite:
- `TECHNICAL_SPEC.md`
- `IMPLEMENTATION_PLAN.md`

Также было предложено использовать Next.js + SQLite + Drizzle + Docker, а Amazon Cognito — для входа и паролей. AWS подключать после того, как приложение заработает локально.

## 5. Файлы проекта

В доступной рабочей папке были созданы следующие документы:

- `TECHNICAL_SPEC.md` — техническая спецификация.
- `IMPLEMENTATION_PLAN.md` — поэтапный план реализации.
- `DEFERRED_FEATURES.md` — отложенные функции и технический долг.
- `PROJECT_DECISIONS.md` — актуальные решения проекта.

### Текущие архитектурные ориентиры
- Next.js + TypeScript.
- SQLite через Drizzle ORM.
- Локальная разработка должна работать без AWS и без платного AI API; для тестов использовать mock AI provider.
- AWS и Terraform подключать после локальной разработки.
- Начальный облачный вариант — один EC2-инстанс; `t4g.nano` с 512 MiB RAM рассматривается как эксперимент и может оказаться слишком тесным.
- GitHub Actions для CI/CD; для доступа к AWS предпочтителен OIDC вместо постоянных ключей.
- Amazon Cognito User Pools предложен как вариант авторизации email/пароль; вход через Apple отложен.
- Секреты не хранить в репозитории и не отправлять на клиент.
- Файл SQLite должен храниться на постоянном томе и не удаляться при деплое.
- Резервные копии должны попадать в приватный S3, а восстановление нужно проверять.

- Этот файл — экспорт доступной пользовательской переписки по теме, а не побайтовая выгрузка внутренней истории ChatGPT. Служебные сообщения и вызовы инструментов исключены.

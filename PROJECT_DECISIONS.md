# Cards No Cards — решения проекта

Этот файл фиксирует актуальные решения. Если они расходятся с черновыми предположениями в других документах, приоритет у этого файла.

## Решено для MVP

1. **Название:** Cards No Cards.
2. **Внешний вид:** тёмная тема.
3. **Языки:** испанский и русский.
4. **Импорт:** свободный текст. ИИ выделяет слова и выражения, предлагает перевод/нормализацию и группирует материал по темам и частям речи.
5. **Количество новых слов за занятие:** пользователь может менять в настройках.
6. **Продолжительность занятия:** пользователь может менять в настройках.
7. **AI-модель:** выбор модели через настройки приложения. Реализовать через провайдерный слой; ключи и вызовы API остаются на сервере. Доступные модели должны определяться конфигурацией приложения, а не обещаться заранее.
8. **Резервные копии:** сохранять копии SQLite в приватный S3 bucket. На старте не вводить сложные политики жизненного цикла/архивации. Всё равно обеспечить безопасное создание копии SQLite/WAL и проверить восстановление.
9. **Первый доступ к приложению:** можно временно использовать адрес/API без собственного домена. Не передавать пароль или токены по обычному HTTP; HTTPS нужен до реального публичного использования авторизации.

- Количество новых слов на занятие.
- Целевая продолжительность занятия.
- Выбранная AI-модель (из поддерживаемых и настроенных приложением).

## Облачный регион

Пользователь предпочитает регион AWS в Европе, как можно ближе к Испании. `eu-east-1` не является стандартным идентификатором региона AWS. В качестве кандидатов проверить актуальную доступность и цены для `eu-west-1` (Ireland), `eu-south-2` (Spain, если доступен для нужных сервисов) или `eu-central-1` (Frankfurt). Перед созданием инфраструктуры сверить EC2, Cognito, S3 и другие нужные сервисы в выбранном регионе, а также цены. Не выбирать регион автоматически до этой проверки.

## Архитектурные ограничения, которые остаются в силе

- Next.js + TypeScript.
- SQLite через Drizzle ORM, без отдельного сервера базы данных.
- Локальная разработка должна работать без AWS и без платного AI API; для тестов использовать mock AI provider.
- AWS/Terraform подключать после локального MVP.
- Один личный EC2-инстанс как начальная экспериментальная конфигурация; `t4g.nano` с 512 MiB RAM может оказаться слишком тесным.
- GitHub Actions; для AWS использовать OIDC и краткоживущие полномочия, а не постоянные AWS access keys.
- Секреты не хранить в репозитории и не отправлять на клиент.
- Не добавлять инфраструктуру с постоянными расходами без обоснования.
